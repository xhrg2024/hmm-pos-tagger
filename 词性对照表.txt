# 北大词性标注集（PKU POS Tagset）对照表
# ============================================================
# 标签	中文名称	英文名称	说明与示例
# ============================================================

# ===== 名词类 =====
n	名词	noun	普通名词。例：经济、政策、技术、学生
nr	人名	person name	人名。例：江泽民、朱镕基、李瑞环
ns	地名	place name	地名。例：北京、中国、上海
nt	机构名	organization name	机构团体名。例：清华大学、国务院、北京大学
nz	其他专名	other proper noun	其他专有名词。例：奥运会、诺贝尔奖
nx	字母词	letter word	含字母的词。例：CD、DNA、GDP

# ===== 动词类 =====
v	动词	verb	普通动词。例：研究、发展、推动、学习
vn	名动词	verbal noun	兼有名词功能的动词。例：改革、投资、培训
vd	副动词	verbal adverb	作状语的动词。例：进行（研究）、予以（解决）

# ===== 形容词类 =====
a	形容词	adjective	普通形容词。例：重要、伟大、美丽、优秀
an	名形词	adjectival noun	兼有名词功能的形容词。例：安全、方便
ad	副形词	adjectival adverb	作状语的形容词。例：快速（增长）、大幅（提高）

# ===== 副词类 =====
d	副词	adverb	副词。例：正在、已经、最、非常、十分

# ===== 代词类 =====
r	代词	pronoun	代词。例：我、他、这、那、什么

# ===== 数词与量词 =====
m	数词	numeral	数词。例：一、百、千、第一
q	量词	classifier	量词。例：个、年、次、种

# ===== 介词与连词 =====
p	介词	preposition	介词。例：在、从、对、关于
c	连词	conjunction	连词。例：和、与、或、但是

# ===== 助词类 =====
# u 为助词总类，本项目 HMM 模型统一使用 u；jieba 分词器将其细分为以下子类
u	助词	particle	助词（总类）。例：的、了、着、地、得
uj	结构助词	structural particle	结构助词"的"。例：美丽的花、我的书
ul	动态助词	perfective particle	动态助词"了"。例：吃了饭、走了
ug	经历助词	experiential particle	经历助词"过"。例：去过、看过
ud	状语助词	adverbial particle	状语标记"地"。例：慢慢地走、高兴地跳
uv	补语助词	complement particle	补语标记"得"。例：跑得快、做得好
ue	语气助词	modal particle	语气助词"么/呢"。例：好吗、是啊

# ===== 叹词与拟声词 =====
e	叹词	interjection	叹词。例：哦、啊、唉
o	拟声词	onomatopoeia	拟声词。例：哗啦啦、轰隆

# ===== 方位词与处所词 =====
f	方位词	localizer	方位词。例：上、下、里、中、前、后
s	处所词	locative word	处所词。例：这里、那里、到处

# ===== 时间词 =====
t	时间词	time word	时间词。例：今天、明年、现在、目前

# ===== 区别词 =====
b	区别词	distinguishing word	区别词（非谓形容词）。例：男、女、大型、初级

# ===== 语素类 =====
Ng	名语素	noun morpheme	名词性语素。
Vg	动语素	verb morpheme	动词性语素。
Ag	形语素	adjective morpheme	形容词性语素。
Tg	时间语素	time morpheme	时间词性语素。
Dg	副词语素	adverb morpheme	副词性语素。

# ===== 其他 =====
j	简称	abbreviation	简称略语。例：北大、人大、中科院
l	习用语	idiom	习用语。例：自然语言、高新技术
i	成语	chengyu	成语。例：改革开放、与时俱进
k	后接成分	suffix	后接成分（后缀）。
h	前接成分	prefix	前接成分（前缀）。
y	语气词	modal particle	语气词。例：吗、呢、吧、啊
z	状态词	state word	状态词。例：漆黑、笔直、雪白

# ===== 标点符号 =====
w	标点	punctuation	标点符号。包括逗号、句号、引号、括号等。

# ============================================================
# 说明：
# 1. 本表基于北京大学计算语言学研究所词性标注集（PKU POS Tagset）
# 2. 语素类标签（Ng, Vg, Ag 等）表示构词成分，一般不出现在独立词语标注中
# 3. 助词细分标签（uj, ul, ug, ud, uv, ue）为 jieba 分词器使用的细分标签，
#    本项目 HMM 模型统一归入 u（助词）进行统计
# 4. 语素类标签（Ng, Vg, Ag 等）表示构词成分，一般不出现在独立词语标注中
# ============================================================
